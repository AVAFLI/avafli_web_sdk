Actions

The experience is exclusively auto-opened by the SDK — there is no manual launch API. "Replay auto-open" clears today's once-per-day mark and reloads so the auto-open engine fires again (same streak day). "Simulate next day" also clears the mock claim, so the SDK auto-opens and auto-claims the next streak day. "Reset user" clears everything (email consent, streak, impression cap).
